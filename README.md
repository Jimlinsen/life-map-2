# 人生地图 5.1 (Life Map)

> **版本 5.1.0** · [变更日志](CHANGELOG.md)

基于紫微斗数与八字命理的可视化人生轨迹分析工具。输入出生信息，生成包含命盘、人生轨迹、关系引力场的完整人生地图。

```
人生轨迹 = 初始速度(八字) + ∫关系引力场dt
r(t) = r₀ + ∫v₀dt + Σ∫(G·Mⱼ/|rⱼ-rᵢ|²)dt
```

同八字不同命的核心解释：**相同的初始速度，不同的引力场**。

---

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173/lifemap/
npm run build      # 生产构建
npm run preview    # 预览构建产物
npm test           # 运行测试（Node 内置测试运行器，零依赖）
```

### 命令行取数

同一套引擎也可以直接跑，输出一份完整的命理档案 JSON：

```bash
node scripts/analyze.mjs --date 1990-05-15 --hour 3 --gender 男
node scripts/analyze.mjs --date 1990-05-15 --hour 3 --gender 男 \
     --events events.json --relationships relationships.json
```

`--hour` 为时辰索引（0=子时 23-1点 … 11=亥时 21-23点），`--today` 可覆盖"今天"。
命理大师智能体（`destiny-master`）即以该脚本为唯一取数来源。

部署到 GitHub Pages 等子路径时，`vite.config.js` 中的 `base: '/lifemap/'` 已配好。

## 理论模型

### 人生影响力系统

四柱 = 四大关系节点（引力源）：

| 柱位 | 关系 | 峰值影响 | 映射宫位 |
|---|---|---|---|
| 年柱 | 祖上·父母 | 0–20 岁 | 父母宫、福德宫 |
| 月柱 | 社会·事业 | 20–50 岁 | 官禄宫、财帛宫、迁移宫 |
| 日柱 | 自我·配偶 | 终身 | 命宫、夫妻宫 |
| 时柱 | 子女·晚年 | 45–100 岁 | 子女宫、田宅宫 |

### 觉醒层级

| 层级 | 名称 | 与八字的关系 | 事件影响倍率 |
|---|---|---|---|
| L1 | 执行层 | 被八字"决定" | ×1.5 |
| L2 | 协调层 | 开始"观察"八字 | ×1.2 |
| L3 | 创新层 | 与八字"对话" | ×1.0 |
| L4 | 整合层 | "运用"八字 | ×0.8 |
| L5 | 超越层 | 八字是"工具" | ×0.5 |

觉醒层级由命盘格局清浊、印食强弱、五行均衡**推演得出**，控制台实时显示"推演值"；手动拖动滑杆可覆盖，点「回到推演值」还原。

### 关系引力的衰减

关系不是恒定的。质量随时间衰减（子女关系例外，随年岁增强）：

| 关系 | 最大质量 | 衰减起点 | 年衰减率 |
|---|---|---|---|
| 父母 | 2.0 | 18 岁 | 0.02 |
| 配偶 | 2.5 | 不衰减 | 0 |
| 子女 | 2.0 | 不衰减 | −0.01（增长） |
| 兄弟姐妹 | 1.2 | 25 岁 | 0.03 |
| 挚友 | 1.5 | 自起始年龄 | 0.01 |
| 贵人 | 1.8 | 自起始年龄 | 0.05 |
| 恩师 | 1.6 | 自起始年龄 | 0.02 |
| 仇人 | 1.5 | 自起始年龄 | 0.03（负极性） |

关系状态：ended ×0.3、distant ×0.5。

### 觉醒测评

**五维问卷，每维四选一**（觉察 / 边界 / 延迟 / 承担 / 长期），共 15 分：

| 维度 | 问的是什么 |
|---|---|
| 觉察 | 能否看见自己的行为模式 |
| 边界 | 能否说出「不」而不愧疚 |
| 延迟 | 情绪与行动之间是否有间隔 |
| 承担 | 能否为自己的选择负责 |
| 长期 | 是否为三年后的自己留余地 |

分层标定与应用自身的层级定义对齐：五维全 0 → L1 执行层；全 1 → L2 协调层；
**全 2 → L3 创新层**（即「能延迟反应、能说不、能负责」）；13 分 → L4 整合层；全满 → L5 超越层。

**与命盘推演对照** —— 问卷自评会与命盘由格局清浊、印食强弱、五行均衡推演出的层级比对：

- 自评高于推演 → 你实际走在了命盘前面，觉醒已领先于先天的初始配置
- 自评低于推演 → 推演显示的层级里有一部分尚未在日常中兑现，多半是盲区

**命格觉醒课题** —— 15 个命格各有专属的课题、盲区、觉醒标志、注意事项、关系表现与日常练习：

| 类别 | 命格 |
|---|---|
| 八格 | 正官格、七杀格、正财格、偏财格、食神格、伤官格、正印格、偏印格 |
| 比劫 | 比肩格、劫财格、建禄格 |
| 特殊 | 杂气格、从格、专旺格、气局格 |
| 兜底 | 器用格（格局不纯者） |

未收录的格局按十神组归并（如「杂气财格」→ 杂气格，「从财格」→ 从格，「曲直」→ 专旺格，「火局」→ 气局格）。

### 影响立场分析

把「关系对我的作用」与「我对关系的作用」拆开，用觉醒层级度量这个不对称：

```
mass     = 关系引力质量（已含时间衰减）
incoming = mass × multiplier          对我的影响（mult = 觉醒层级的「事件影响倍率」）
outgoing = mass × (2 - multiplier)    我对它的影响
postureGap = outgoing - incoming
```

- 觉醒越高，别人给我的作用被衰减得越厉害（mult 越小），而我施加出去的作用相对越强（2−mult 越大）
- **L3 创新层是平衡点**（mult = 1，进出一致）；L1/L2 为「被牵引」，L4/L5 为「主导者」
- 负极性关系（仇人）单独按极性定向，避免「被仇人拖住」被误读成「我主导」

面板输出：什么样的人对我影响大（按类型汇总）、我容易对什么样的人影响大、逐条立场明细、L1–L5 觉醒对照下的净立场差，以及针对性建议。

### 格局透出分析

三命通会取格以月令为纲，看月支藏干是否透出天干：

1. **月令藏干分层**（本气 / 中气 / 余气）—— 藏干天干与十神直接取自 lunar-javascript，已对 1980–2025 年 6480 组交叉验证零误差
2. **透出判定** —— 只认年干、月干、时干；日干是日主本身，不算透出
3. **取格优先级** —— 透干优先 → 本气 → 中气 → 余气 → 杂气
4. **间接引出** —— 若月令藏干未透出，则由你标记的**关系与事件**把它引出：关系类型与事件类型各自对应一组十神（如父母→印、配偶→财、子女→食伤、事业突破→官杀），与藏干十神一致者即为「引出」；负极性证据（离婚、重大疾病、财务危机、丧亲）另列为「克伐激出」，单独成栏而非混入正面依据

结论会直接点明：这个格局是**天生自带**（直透，不依赖他人），还是**靠你主动经营的关系才显化**（借势引出——关系网络直接参与了你命格的成立）。

### 龙穴砂水

`life_map_5.js` 引擎中的四维风水映射：

- **龙**：大运五行循环（顺龙/逆龙/盘龙）× 觉醒状态
- **穴**：核心锚点 + 事件凝聚（真穴/虚穴/动穴/弱穴）
- **砂**：四方位关系力网络（左右前后）
- **水**：化曜与关系变迁（来水充沛/去水过急/聚水成潭/水枯源断）

## 双引擎说明

项目并存两套命理实现，二者**都保留**，由 `tests/consistency.test.js` 锁定公共口径：

| | `life_map_5.js` | `src/core/**` |
|---|---|---|
| 入口 | `generateLifeMap5()` | React 应用内部 |
| 独有 | 龙穴砂水四维、关系衰减模型、滴天髓/三命通会完整档案、用神三法（扶抑/调候/通关） | 精确八字排盘、大运排盘、紫微全量分析、五运六气、事业/婚姻分析、自动预测 |
| 公共 | 事件质量表、关系质量与衰减参数、引力公式、轨迹公式 | 同左 |

已知且有意保留的差异（已在测试中显式断言）：觉醒层级倍率表（lib `eventMassMultiplier` vs 应用 `multiplier`）、lib 独有的两个事件类型（重大决定 / 重大背叛）。
